## Proposed Prompt changes

1. Fix the audit block's "Total CP received" line so it matches the bottom CP summary's "Completed" figure exactly, rather than sometimes including currently-enrolled or total-planned CP. Confirmed across 4 separate responses (BBIS\_02, BBIS\_02.1, BBIS\_02.2), always wrong in the same direction.  
2. Extend the "must come from lookup\_subjects\_tool" instruction to explicitly cover subjects the student reports as already complete, not only the newly generated draft plan. This is the direct cause of the placeholder "CSIT Elective (300-level)" codes and the historical-subject name mismatches in BBIS\_02/BBIS\_03.  
3. Flag to the team as an open product question rather than a prompt bug: should previously shown future elective subjects stay pinned across unrelated follow-up turns, or is full regeneration each time (current behaviour) the intended design.  
4. BBIS\_04 still needs to be run before this can be considered a complete pass for the BIS degree — currently the only untested case in this batch.
